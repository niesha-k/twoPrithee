This is a program that prints out a sonnet, stops at a random word, and then prompts the user for that random word.
If they get it right or wrong, the program continues, and prompts the user for another random word on another random line
until the user gets three words correct or three words incorrect.

Compile:
javac -d out src\main\java\Main.java src\main\java\Prithee.java

Then run:
java -cp out Main
